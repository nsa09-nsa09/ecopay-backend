3. КАКИЕ ДАННЫЕ МЫ ОБРАБАТЫВАЕМ

3.1. Данные учётной записи: адрес электронной почты, отображаемое имя, зашифрованный (хешированный) пароль, выбранный аватар, роль, статус учётной записи.

3.2. Данные для Телеком-комнат: номер телефона и/или иные идентификаторы подключения, предоставляемые вами для организации совместного использования тарифа. Такие данные хранятся в зашифрованном виде и раскрываются Владельцу Комнаты только после успешной оплаты и только в объёме, необходимом для предоставления доступа.

3.3. Платёжные данные: сведения об операциях (суммы, статусы, идентификаторы транзакций). Полные реквизиты банковских карт обрабатываются на стороне лицензированного Платёжного провайдера; Оператор не хранит номера карт и коды безопасности.

3.4. Технические данные: IP-адрес, сведения об устройстве и браузере (user-agent), журналы событий, данные о входах и активности, файлы cookie и аналогичные технологии.

3.5. Данные о репутации и взаимодействиях: отзывы, рейтинги, обращения в поддержку, сведения о спорах.

3.6. Данные геолокации: обрабатываются только с вашего отдельного согласия для отображения приблизительного качества связи операторов; данные носят ориентировочный характер.
